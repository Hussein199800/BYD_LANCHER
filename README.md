# BYD_LANCHER

لانشر/لوحة معلومات عربية لشاشة BYD Song Pro DM-i (DiLink 5) — قيد التطوير.

## المرحلة الحالية: تطبيق الفحص `probe/`

قبل بناء الواجهة نحتاج أن نعرف ما الذي تتيحه السيارة فعلاً. `BYD Probe` تطبيق صغير
**للقراءة فقط**:

- يكتشف أصناف `android.hardware.bydauto` الموجودة في نظام السيارة.
- يستدعي دوال القراءة فقط (`get*` / `is*` / `has*`) ويسجّل القيمة أو سبب الفشل.
- يسجّل مواصفات الشاشة وإصدار النظام وأذونات BYD ومستوى حمايتها.
- لا يستدعي أي دالة `set*` ولا يرسل أي أمر للسيارة، ولا يرسل بيانات إلى الإنترنت.
- يحجب رقم الهيكل (VIN) والمعرّفات المشابهة في التقرير.

### التثبيت

نزّل `byd-probe.apk` من صفحة Releases (الإصدار `probe-latest`) وثبّته من متصفح السيارة.

### الحصول على التقرير

بعد اكتمال الفحص يظهر ملخص على الشاشة، والتقرير الكامل يُحفظ في:

- مجلد التنزيلات: `Download/byd_probe_report.txt`
- أو من هاتف على نفس الشبكة: `http://<عنوان الشاشة>:8765` (العنوان يظهر في الملخص، والتطبيق مفتوح).

### البناء محلياً

```
./gradlew :probe:assembleDebug
```

الناتج: `probe/build/outputs/apk/debug/probe-debug.apk`

> ملف `keystore/debug.keystore` مفتاح تجريبي علني لتوحيد توقيع نسخ الفحص فقط، وليس مفتاح نشر.
